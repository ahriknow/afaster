# 升级指南

本项目采用 **快速适配发布** 策略。当以下情况发生时会发布新版本：

- 上游框架 afast / afastdata 发布新版本
- 核心依赖（sqlx、reqwest、jsonwebtoken 等）有重大更新
- 第三方平台 API（GitHub、微信、腾讯云、阿里云 等）发生接口变更
- 框架自身功能扩展或内部重构

## 版本变更记录

| 版本 | 日期 | 主要变更模块 | 升级指南 |
|------|------|----------|----------|
| 0.0.1 | 2026-05-29 | 初始版本 | [v0.0.1](v0.0.1.md) |

## 升级流程

1. 修改 `Cargo.toml` 中 `dependencies.afaster` 的版本号
2. 查看当前版本 到 目标版本所有变化 upgrade/vX.Y.Z.md
3. 按发布顺序逐版本修改
